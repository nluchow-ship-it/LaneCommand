# Build Lane Command in GitHub (no software install required)

1. Create a **new empty GitHub repository**.
2. Upload the **contents of this folder** to the repository root. You should see `app`, `.github`, `build.gradle.kts`, and `settings.gradle.kts` at the top level.
3. Commit the files.
4. Open **Actions**.
5. Select **Build Lane Command APK**.
6. Click **Run workflow**.
7. Wait for a green tick.
8. Open the completed run and download the **LaneCommand-APK** artifact.
9. Unzip it. Inside is `LaneCommand.apk`.
10. Move the APK to your Android phone and install it.

The app requests **no internet permission**, contains **no ads**, and contains **no purchases**.
